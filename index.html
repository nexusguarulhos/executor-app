executor

executor is a private automation tool that runs on a server. It connects one Google account to that server so the owner's own scripts and assistants can read and manage his mail, calendar and files.

It is not a public service. Nobody else can sign up, and it is not offered to other people or organisations.

The Google sign-in screen for this tool links here so that you can see who runs it and how data is handled. The details are in the privacy policy.
